Doing work

Tools

Twenty-three tools across four crates, behind one trait with seven methods, two of which have defaults. Sixteen register without a Chrome, because WebFetch, WebSearch and the five browser tools withdraw themselves and say so rather than failing when called. Until 2026-09-05 WebSearch needed a search vendor's key instead; it is a results page in the same Chrome now, and the web page says what that took. I had this page at twenty-one until 2026-09-01, and it counted neither BashOutput nor KillShell. This chapter is what a tool declares about itself and what it does when called. Whether you get asked first is the gate's business, not the tool's.

Four crates, one trait, and the thing the trait cannot hold

tools/fs is eight tools over the filesystem and a shell: six, plus BashOutput and KillShell, which read and stop a command started in the background. tools/tasks is four tools over one markdown file. tools/web is two stateless tools plus five that drive a live Chrome. tools/lsp is four that ask rust-analyzer instead of guessing from text. Each crate exposes one builder function. Calling it is the only supported way to get the set, because three of the four share mutable state that ToolCtx has no room for.

Two rules I run through every crate apply on every page below. Emptiness is a result: a read of an empty file, a glob matching nothing, a grep with no hits and a search with no results all succeed. And a cut says what was lost and what would get it back, or says plainly that nothing would.

crates/tool-api/src/lib.rs — module doc
  1. The Tool trait, and what a tool declares Seven methods, three booleans, three error variants, and a registry that panics on a declaration contradicting itself. Includes the field that was deleted for having no reader, and the one that was kept by being given one.
  2. ToolOutcome: one type, two audiences Why every result is written twice, what each tool puts in display, and the four constructors.
  3. The truncation rule Name the limit, name the loss, name the remedy, or say that no argument raises it. Every cut in the workspace, tabulated, with the defect the rule was written after.
  4. ToolCtx, and the state it has no room for Three fields and one absence. Three crates keep session state in their tool structs instead, and each documents the same hazard in different words.
  5. Path containment, in one implementation resolve, canonical_prefix, and the two escapes it catches against the two it cannot. Plus a suspected defect in display.
  6. Read, Write, Glob, Grep Every argument, every cap, every refusal message. The read tracker that makes Write's refusal mean something, and the two skips Grep reports differently.
  7. Edit, and its two ways of saying where A literal anchor and a hash-checked address, in one tool. Three checks, the refusal rewritten after watching a model read it, and the measured cost of the labels.
  8. Bash: a shell, and what that costs Shell selection and why WSL is refused, the 16-name environment allowlist, exit status as an answer, the drain race, and a test that cannot go red.
  9. The task list: four tools over one file A markdown document a person keeps open while the agent works. The parser that re-emits untouched bytes, the hash-guarded write, and the two writers named in the gate's exempt list.
  10. The web: two tools, five more, and a browser Registration that refuses to ship a tool that cannot work, the per-host grant, the cross-origin re-ask, and a refusal that names a file Emma never reads.
  11. Code intelligence: asking rust-analyzer Four read-only tools, the readiness signal that replaced a heuristic declaring ready at 0.36 seconds, containment applied to what comes back, and the crate that uses the weak truncation form.

What this chapter does not settle

Each page carries its own amber. Collected, the largest gaps are that Bash's lost-drain branch has no test that can reach it, that classify's unit test passes on every platform for the same reason the defect exists, and that the browser crate's two live numbers rest on prose and on a handful of runs nobody kept. unverified I think these are the largest gaps, and that is a judgement, not a count. Settled by an audit that lists every behavioural claim across the eleven pages and marks the ones with no repeatable evidence behind them.
